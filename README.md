## 📖 Sobre

Este repositório documenta, em formato de "saga", tudo o que estou aprendendo e praticando em **DevOps**: laboratórios, scripts, pipelines, anotações e projetos. Cada capítulo é um tema, com código funcional e notas sobre o que deu certo (e o que quebrou).

**Objetivos:**
- Consolidar o aprendizado de forma prática e organizada
- Criar um portfólio público e versionado
- Servir de referência rápida para mim e para quem estiver começando

## 🚀 Como usar

```bash
# Clone o repositório
git clone https://github.com/SEU_USUARIO/DevOps_Saga.git

# Navegue até o capítulo desejado
cd 04-docker
cat README.md
```

## 🤝 Contribuindo

Sugestões, correções e boas práticas são bem-vindas! Abra uma **issue** ou envie um **pull request**.

2. Crie uma branch: `git checkout -b feature/minha-melhoria`
